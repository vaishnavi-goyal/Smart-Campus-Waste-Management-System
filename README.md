# 🌱 Smart Campus Waste Management System

## 📌 Project Overview
The **Smart Campus Waste Management System** is a dashboard-based project developed to support better waste monitoring and sustainable practices in college campuses.

The project focuses on monitoring different types of waste, such as food waste, plastic waste and paper waste, according to their category, location and date.

It uses data analytics and visualisation to make waste records easier to understand and analyse.

## 🎯 Objectives
- Monitor different categories of campus waste.
- Analyse waste according to location and date.
- Visualise waste data through interactive charts.
- Encourage proper waste segregation and recycling.
- Support data-driven sustainability decisions.

## 🛠️ Technologies Used
- Python
- Pandas
- Streamlit
- Plotly
- CSV Dataset

## ⚙️ Key Features
- Waste analysis by category.
- Location-wise waste distribution.
- Waste generation trends over time.
- Interactive data filters.
- Waste records and data tables.
- Downloadable CSV reports.

## 🔄 Working Process
The system follows five main steps:

1. **Collect:** Collect waste information such as date, location, type and weight.
2. **Store:** Store the information in a CSV file.
3. **Analyse:** Process data using Python and Pandas.
4. **Visualise:** Display interactive charts using Streamlit and Plotly.
5. **Act:** Use insights to support better waste management practices.

## 🚀 How to Run the Project

**Step 1: Clone the repository**
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 2: Open the project folder**
```bash
cd Smart-Campus-Waste-Management
```

**Step 3: Install the required libraries**
```bash
pip install -r requirements.txt
```

**Step 4: Run the Streamlit application**
```bash
streamlit run app.py
```
